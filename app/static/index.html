CourseMate Architecture & Design Notes

Built to demonstrate production MongoDB design patterns in system design interviews:

1. Schema Design: Embedding vs. Referencing

Embed small, bounded data with 1:1 or 1:few cardinality (tags, metadata, audit timestamps).
Reference large, unbounded data: chunks reference documents via doc_id, avoiding MongoDB's 16MB BSON document limit.

2. Indexes & ESR Rule

Compound index on (course_id, created_at) follows the Equality-Sort-Range rule.
Text index on document titles for keyword discovery, unique index on email and course code.

3. Atlas Vector Search ($vectorSearch)

Hierarchical Navigable Small World (HNSW) index on 384-dim embeddings. Falls back to brute-force cosine similarity if run on local standalone MongoDB.

4. Replication & Failover

Local 3-node replica set (rs0) with automatic Raft-like election when primary dies. In Atlas M0, a multi-AZ replica set runs underneath automatically.
